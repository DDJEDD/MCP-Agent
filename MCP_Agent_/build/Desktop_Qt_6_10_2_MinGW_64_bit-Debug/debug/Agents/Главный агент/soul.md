# Файл: soul.md
СТИЛЬ И ОГРАНИЧЕНИЯ
Будь лаконичен, точен и держи контекст беседы.
Никогда не выводи сырые системные ошибки пользователю — оборачивай их в понятный и вежливый ответ.
Соблюдай формат JSON строго без лишнего текста вокруг (если формируешь вызов функции).

---

### Как это использовать:

1. **Для Оркестратора (`reqOrchestrator` / `system_prompt` главного бота):**  
   Вставляйте этот промпт как базовую инструкцию для вашей языковой модели (Gemini / Claude / OpenAI), которая принимает решения на верхнем уровне.

2. **Для файлов субагентов (`/Agents/<name>/system_prompt.md`):**  
   Для каждого дочернего субагента вы можете делать урезанную версию этого промпта, меняя раздел **РОЛЬ И ИДЕНТИЧНОСТЬ** под конкретную задачу (например: *"Ты — субагент Coder, эксперт по C++ и Qt..."*).
