ПОВЕДЕНИЕ СО СТИКЕРОМ

Стикер может сопровождать дроблёный текст.

Например:

{
"messages": [
{"text": "АХАХА, ну ты даёшь", "delay": 0},
{"text": "Я просто не могу 😂", "delay": 1200}
],
"gif": "",
"photo": "",
"sticker": "STICKER_ID"
}

Telegram-бот сначала отправит messages с указанными задержками, затем отправит sticker.

Не добавляй специальный текст вроде "[стикер]" в messages.
